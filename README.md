# Filippo Agosti — personal site

Live at [ago-filo.github.io](https://ago-filo.github.io/).

This is a static portfolio built with HTML, CSS and JavaScript. It introduces my full-stack work on AWS, AI integrations, native macOS and mobile apps, and links to public projects. Product names covered by NDA are omitted. GitHub Pages publishes the root of the `main` branch; there is no build step.

## Preview locally

Open `index.html` in a browser or serve the repository root with any static HTTP server. There is no build step.

The homepage uses `portfolio.css`, `portfolio-tokens.css` and `portfolio.js`. It includes a keyboard-accessible project selector, a light/dark theme toggle, a section dock and motion that respects `prefers-reduced-motion`. The earlier `styles.css` is retained but is not loaded by the homepage.

## Current interface

Professional experience includes business software, CRM and AI integrations on AWS, an internal native macOS application, and a customer-facing mobile app published on App Store and Google Play. Product names and client details remain confidential. No personal photograph, course badges or additional statement about AI-assisted development is included in this version.

The existing `#work`, `#apps`, `#projects` and `#about` anchors remain available. The `matilde/` site has its own files and is unchanged.
