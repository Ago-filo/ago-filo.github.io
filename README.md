# Laboratorio · Filippo Agosti

[Apri la lavagna](https://ago-filo.github.io/laboratorio/) per esplorare progetti personali, prototipi e prove. Ogni blocco si apre in una scheda con un indirizzo condivisibile, per esempio [Second Brain](https://ago-filo.github.io/laboratorio/#second-brain).

## Anteprima locale

Apri `laboratorio/index.html` in un browser o servi la radice del repository con un server statico. GitHub Pages pubblica dalla radice del branch `main`. Il sito non richiede una compilazione. La homepage reindirizza a `laboratorio/`.

## Materiali dei progetti

- L’anteprima di PitWall proviene da `docs/comparison.png` del commit [bc1ac73](https://github.com/Ago-filo/Pitwall/blob/bc1ac73234bfb70623f7da0838c6075eaae761d6/docs/comparison.png).
- La schermata di Fantamuretto usa la configurazione dimostrativa. L’immagine dell’autoscuola è un’illustrazione.
- La demo di Second Brain usa un archivio fittizio e comprende una registrazione della configurazione locale.
- Gli importi in Document Workbench appartengono a un esempio sintetico.

Il sito in `matilde/` è indipendente.
